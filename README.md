## 🌐 Department Website – SRKR CSD & CSIT

A centralized department website designed for students and faculty to access department information, updates, resources, activities and communication.

### Tech Stack

- ⚛️ React
- 🐘 PHP
- 🗄️ MySQL
- 🖥️ XAMPP
- 🔧 Git & GitHub

### Key Features

- Responsive and interactive frontend
- Department information and updates
- Student and faculty resources
- Backend and database integration
- Version control using Git and GitHub

🔗 **Website:** [srkrcsdcsit.in](https://srkrcsdcsit.in)

## 🎾 Bhimavaram Live Tennis Auction

A real-time auction management website developed and deployed for a live tennis auction event in Bhimavaram.

### Key Features

- 🔴 Real-time bidding updates
- 👤 Player management
- 🏆 Team allocation
- 📊 Team-wise auction tracking
- 🖥️ Large-screen public auction display
- 🔄 Connected auction control workflow

The system was designed to provide a smooth and clear live auction experience.
